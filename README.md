# 蛇的圖鑑・森間探索所

手機優先、繁體中文的純靜態網站，不需要安裝套件或建置。

直接開啟 `index.html`，或執行 `node server.cjs` 後瀏覽 http://127.0.0.1:4173。

包含四種蛇類圖鑑、棲息地分頁、保育知識、探索導覽、固定小蛇角色、隨機探索與圖鑑開啟動畫。支援鍵盤、原生對話框焦點管理、減少動態效果及手動暫停。

設計依據：`DESIGN.md` 保留提供文件原文；將原本固定桌面版面改為手機優先並放大觸控區。照片存放於 `assets/`，來源與授權記錄在 `assets/sources.json`，知識來源在 `assets/facts.json` 及網站來源視窗。

不含後端、追蹤器或外部字型。網站照片皆為本機資產，可離線閱讀。
